Ferramentas Descartadas Racionalizadas (Sem Excesso)
❌ Docker / Kubernetes
Inadequado para Userscript client-side de navegador (não há containers nem infraestrutura backend).
❌ Banco de Dados Próprio
Toda a persistência de histórico e opções é local via localStorage ou GM_setValue.
❌ Prometheus / Grafana / APM
Inexistência de servidor backend próprio para coleta contínua de métricas.
❌ k6 (Testes de Carga)
Inadequado sem backend. Chrome DevTools e Playwright Trace Viewer inspecionam memória e DOM localmente.
❌ OWASP ZAP / Lighthouse Gate
Redundante e excessivo para o contexto de um script inline de extensão.
❌ ESLint + Prettier
Descartado para evitar duplicidade de linter/formatador (substituídos pelo Biome em Rust).
